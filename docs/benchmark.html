    How the test works

    • The patient is the real program. It uses the same prompt and settings as the program.
    • Claude, an AI model, plays the student and the examiner. The examiner asks the same questions to each model.
    • Claude also plays the judge. The judge compares each patient reply with the case.

    Limits

    • The patient model uses some chance. Two runs of the same test can differ by 2 points, so we pool two or more runs. A difference of a few points between two models can be chance.
    • We improved the cases and the program with the standard questions. So the standard questions can give a result that is a little too good. The check with new questions shows the honest result.
    • The judge can make mistakes. Each verdict and its reason are in the results.
    • There are 8 cases, all in English.
