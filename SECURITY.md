# Security

## Report a problem privately

If you find a security problem in the simulator, please do not open a public issue.

1. Open the **Security** tab of this repository.
2. Press **Report a vulnerability**.
3. Describe what you found and how to repeat it.

You get an answer within a week. Fixes are released as a new version, and the page offers the
**Update** button to everyone.

## What is in scope

- The launchers: `Start on Mac.app`, `Start on Windows.bat`, `Start on Linux.desktop`.
- The local servers in `app/` and the page `app/index.html`.
- The Update feature.

Ollama and the AI model are separate projects. Report problems in them to
[Ollama](https://github.com/ollama/ollama/security).

## Supported versions

Only the latest version gets fixes. The version is shown at the bottom of the page.
