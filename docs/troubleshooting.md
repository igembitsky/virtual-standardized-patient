# If something goes wrong

Problems specific to one system are on its install page: [Mac](install-mac.md#troubleshooting), [Windows](install-windows.md#if-something-goes-wrong), [Linux](install-linux.md#if-something-goes-wrong). These apply to all:

| What you see | What to do |
|---|---|
| Red dot, **Ollama is not running** | Open the Ollama app. The page notices by itself |
| The page will not reload after it sat in the background for a long time | The simulator stopped because the tab went quiet. Double-click the Start file again |
| A page that says "Start it with the launcher" | You opened `index.html` directly. Close it. Double-click the Start file |
| Replies take a long time | Normal without a graphics chip. The first reply is the slowest |
| A case says the file has a problem | A section is missing. The card names it |
| The patient says something wrong | The model is small. Note it and open an issue |
| Your copy has an **Update** button | It is older than 1.3. Download the new version from the [Releases](https://github.com/igembitsky/virtual-standardized-patient/releases) page and replace the folder. Your saved encounters stay |

To report anything else, press **Report a problem** at the bottom of the page. Choose
**Email report** or **Report on GitHub**. The report is filled in for you.
